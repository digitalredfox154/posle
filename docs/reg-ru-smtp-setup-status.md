# Подготовка SMTP для OTP

SSO-вход в ISPmanager shared-хостинга Reg.ru успешно открыт под пользователем `u3543113`. Панель содержит раздел **Mail** для управления техническим ящиком отправителя.

Для shared-хостинга Reg.ru официальный сервер исходящей почты — `mail.hosting.reg.ru`; для SMTP подходит порт `587` с STARTTLS. Перед внесением настроек в runtime VPS должен быть создан отдельный ящик отправителя и установлен уникальный пароль через защищённое хранилище секретов.
