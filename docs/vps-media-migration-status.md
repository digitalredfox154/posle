# Статус переноса медиа на VPS

26 августа 2026 года из объектного хранилища Manus успешно выгружено **17 статических изображений**, используемых публичными страницами сайта. Они перенесены в `/var/lib/posle/uploads` на VPS с сохранением исходных ключей; старые ссылки `/manus-storage/...` перенаправляются приложением на локальные файлы.

Визуальная проверка главной страницы по публичному IP VPS после переноса подтвердила восстановление фонового изображения hero и остальных доступных статических материалов.

Три объекта, связанные с историческими данными кабинета, остаются недоступны: исходное object storage возвращает HTTP 403 и по прямой подписанной ссылке, и через старый proxy. Ссылки и записи базы сохранены без изменений; задача восстановления этих файлов остаётся открытой.
