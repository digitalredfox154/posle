# Доступ к почтовой панели Reg.ru

В карточке активного хостинга Host-0 подтверждена штатная ссылка **«Панель управления ispmanager»** и отдельный webmail Roundcube. Это позволяет создать технический почтовый ящик для отправки OTP-кодов, не меняя MX-записи и не отключая существующий shared-хостинг до переключения сайта на VPS.

Почтовый ящик будет использоваться только как SMTP-отправитель. Его пароль не должен попадать в чат, документы или репозиторий; после создания он должен быть внесён через защищённое управление секретами.
