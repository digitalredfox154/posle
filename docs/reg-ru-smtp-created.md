# Технический SMTP-ящик

В ISPmanager создан отдельный технический ящик `otp@posle-grooming.online` для отправки одноразовых кодов входа. Существующий `noreply@posle-grooming.online` не изменялся.

Пароль ящика уникален и не сохраняется в репозитории, документации или сообщениях. Он должен храниться только в защищённой runtime-конфигурации VPS.
