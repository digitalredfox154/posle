# Технический SMTP-ящик

В ISPmanager создан отдельный технический ящик `otp@posle-grooming.online` для отправки одноразовых кодов входа. Существующий `noreply@posle-grooming.online` не изменялся.

Пароль ящика уникален и не сохраняется в репозитории, документации или сообщениях. Он должен храниться только в защищённой runtime-конфигурации VPS.

26 августа 2026 после подтверждения пользователя начата смена этого пароля. Прямой старый адрес `server17.hosting.reg.ru/ispmgr` возвращает 404, а раздел личного кабинета Reg.ru временно остаётся на экране загрузки. Секрет не отображался и не изменялся; поиск корректного маршрута управления почтой продолжается через кабинет Reg.ru.

Официальный hash-маршрут личного кабинета Reg.ru успешно открылся. В разделе «Хостинги» услуга Host-0 пока не отображается, хотя ранее была активна. Стандартный защищённый адрес ISPmanager `https://server17.hosting.reg.ru:1500/ispmgr` доступен, но однократная проверка с известными данными shared-хостинга завершилась ошибкой авторизации. Новые попытки с иными паролями не выполнялись. Пароль SMTP-ящика остаётся прежним до сброса доступа к услуге через кабинет/поддержку.
